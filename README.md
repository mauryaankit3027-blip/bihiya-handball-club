# Bihiya Handball Club Website

A responsive, custom-coded sports website starter inspired by the clean layout of the Bihar Handball Association reference photo.

## Included files
- `index.html` — homepage, club intro, players/team, tournaments, gallery, contact section
- `style.css` — responsive sports-themed design
- `script.js` — mobile navigation and automatic copyright year
- `assets/` — add your official logo and club photos here

## Preview
1. Download and extract the ZIP.
2. Open `index.html` in Chrome.
3. The starter uses online sample photos and Google Fonts, so an internet connection is needed for those assets.

## Important edits before publishing
1. Replace sample sports photos with your club's own photos.
2. Add real player names, jersey numbers and positions.
3. Replace `YOUR-EMAIL@example.com` in `index.html` with the official club email.
4. Add verified contact information and actual tournament dates/results.
5. Get permission before publishing player photos or personal details.

## Publish FREE with GitHub Pages
1. Create a free GitHub account: https://github.com/
2. Create a new **public** repository, for example `bihiya-handball-club`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the deployment to finish. GitHub Pages will show a free address similar to:
   `https://YOUR-USERNAME.github.io/bihiya-handball-club/`

A custom `.com` domain is not required. GitHub Pages hosting is free for eligible public repositories, but its URL uses the `github.io` domain. Availability and account requirements are controlled by GitHub.

## Alternative free static hosting
You can also publish the same files using Netlify: https://www.netlify.com/ or Cloudflare Pages: https://pages.cloudflare.com/. Check each service's current plan and limits before publishing.

## Current limitations
This is a static website starter. It does not yet include a secure admin dashboard, database, player registration backend, upload system, or live tournament management. Contact email is a placeholder until you update it.
